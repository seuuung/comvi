# 제10주 3차시: 8장 기계 학습(1) - 기초 및 신경망 개요

본 자료는 기계 학습의 핵심 정의와 학습 패러다임, 모델의 일반화 능력을 평가하기 위한 통계적 방법론, 그리고 연결주의 모델의 시초인 신경망의 기초 구조를 다룹니다.

## 1. 기계 학습의 정의와 기초

### 1.1 Mitchell의 정의
*   **핵심 요소:** 작업(Task $T$), 경험(Experience $E$), 성능 척도(Performance Measure $P$).
*   **정의:** 작업 $T$를 수행함에 있어 경험 $E$를 통해 성능 $P$가 개선된다면, 해당 프로그램은 학습한다고 정의함.
*   **컴퓨터 비전 적용:** $T$는 분류/인식, $E$는 학습용 데이터셋, $P$는 인식률에 해당함.

### 1.2 학습 데이터에 따른 분류
1.  **지도 학습 (Supervised Learning):** 레이블(부류 정보 $t$)이 포함된 샘플 $(x, t)$를 사용함. 최적의 매개변수 $\Theta$를 찾아 결정 경계(Decision Boundary)를 형성하는 것이 목표임.
2.  **비지도 학습 (Unsupervised Learning):** 레이블 없이 특징 벡터 $x$만 사용함. 데이터의 내재적 구조를 파악하는 군집화(Clustering)가 대표적임.
3.  **준지도 학습 (Semi-supervised Learning):** 레이블이 있는 소량의 데이터와 레이블이 없는 대량의 데이터를 함께 사용함. 최근 인터넷 환경에서 데이터 수집은 쉬우나 레이블링 비용이 높은 상황에서 중요성이 부각됨.

## 2. 모델 평가 및 재샘플링 (Resampling)

데이터셋이 한정적일 때 모델의 통계적 신뢰도를 확보하기 위한 기법들입니다.

### 2.1 k-겹 교차 검증 (k-fold Cross Validation)
*   **과정:** 전체 데이터를 $k$개로 등분하여, $k-1$개로 학습하고 나머지 1개로 테스트하는 과정을 $k$번 반복함.
*   **결과:** $k$번 수행한 성능의 평균을 최종 성능으로 채택하여 특정 데이터 분할에 따른 편향을 최소화함.

### 2.2 붓스트랩 (Bootstrap)
*   **원리:** 중복 허용(Replacement) 샘플링을 통해 여러 개의 훈련 집합을 생성하고, 각 집합에서 얻은 성능의 평균을 구함. 앙상블 학습의 기초가 되는 아이디어임.

## 3. 신경망 기초: 퍼셉트론에서 MLP까지

### 3.1 퍼셉트론 (Perceptron)
*   **구조:** 입력 벡터에 가중치를 곱하고 편향(Bias)을 더한 뒤, 계단 함수(Step Function)를 거쳐 이진 출력(+1/-1)을 내놓는 선형 분류기임.
*   **한계:** **선형 분리 불가능(Linearly Inseparable)**한 문제(예: XOR 문제)를 해결할 수 없음. 단일 퍼셉트론으로는 XOR 문제에서 최대 75%의 정확도만 달성 가능함.

### 3.2 다층 퍼셉트론 (Multi-Layer Perceptron, MLP)
*   **확장:** 입력층과 출력층 사이에 **은닉층(Hidden Layer)**을 도입함.
*   **원리 (XOR 해결 사례):** 
    1. 첫 번째 단계에서 여러 개의 퍼셉트론이 특징 공간을 새로운 공간으로 매핑(Mapping)함.
    2. 새로운 공간에서는 선형 분리가 가능해지며, 최종 출력층의 퍼셉트론이 이를 분류함.
*   **의의:** 비선형 결정 경계를 형성할 수 있게 되어 복잡한 패턴 인식 문제를 해결하는 발판을 마련함.
